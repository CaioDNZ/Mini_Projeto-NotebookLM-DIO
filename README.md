# Mini_Projeto-NotebookLM-DIO
Um notebook especialista num tema que você quer aprender, neste caso Minecraft HG, alimentado por fontes confiáveis em mais de um formato, como vídeos do YouTube e artigos. Ele responde com base nelas, mostra de onde tirou cada resposta e ainda gera materiais de estudo a partir do que leu.

 Neste caso foram usadas fontes como:
 - Canais de youtube relacionados ao tema;
 - Servidores oficiais;
 - Site oficial do Minecraft;
 - Artigos e Discussões no Reddit;
 - Fórum específico para esse modo de jogo.
